🚀 Buka Editor i++

📖 Cara Menggunakan i++

Selamat datang di i++ Studio! Di sini kamu bisa membuat program dengan cepat dan menyimpannya ke dalam format .ipp.

  1. Klik tombol Buka Editor i++ di atas.
  2. Tulis kode programmu di area layar hitam (Editor).
  3. Klik tombol ▶️ Jalankan Kode untuk melihat hasilnya.
  4. Gunakan tombol 💾 Simpan (.ipp) untuk menyimpan kodemu ke HP/Laptop, dan 📂 Open (.ipp) untuk melanjutkannya nanti.

⚡ Daftar Perintah Resmi i++

i++ memiliki perintah bawaan berbahasa Indonesia yang sangat mudah dipahami. Berikut daftar perintah yang bisa kamu ketik di editor:

Perintah Fungsi
Notif("Pesan") Memunculkan notifikasi pop-up cantik di pojok layar.
Getar(500) Membuat HP bergetar selama setengah detik (500 milidetik).
Bicara("Halo") Sistem akan berbicara membacakan teks tersebut.
LayarPenuh("html:...") Membuka game atau desain web buatanmu dalam mode Layar Penuh.
BikinBrowserMelayang(...) Membuka jendela kecil/pop-up yang bisa digeser-geser.

🌐 Tentang i++ Engine

i++ dibuat menggunakan apa?
i++ Engine dibangun murni menggunakan teknologi Web Native (HTML5, CSS3, dan JavaScript V8 Engine). Karena berjalan langsung di atas environment browser, aplikasi ini sangat ringan, tidak memakan RAM, dan tidak perlu proses kompilasi yang lama.
